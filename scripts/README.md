# Instalación del acceso gráfico a la aplicación

`instalar_acceso_gui.sh` registra TIC3 - Captura BMI270 en el menú de aplicaciones
de la Raspberry. Utiliza el lanzador `raspi/launcher.py` y comprueba que Tkinter
esté disponible. Se ejecuta una vez desde el escritorio del usuario:

```bash
bash scripts/instalar_acceso_gui.sh
```

La preparación completa está en el [README del proyecto](../README.md#instalación-y-operación-gráfica).
